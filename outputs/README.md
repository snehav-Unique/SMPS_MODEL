# Results and evidence

| Directory | Contents |
|---|---|
| `final_verification/` | Final five-model FP32 replay, timing, hashes and charts |
| `final_validation/` | Final five-model validation and corruption statistics |
| `models/` | Original results grouped by architecture |
| `predictions/` | Individual-model and earlier ensemble CSVs |
| `gradcam/`, `eda/` | Explainability and dataset analysis |
| `efficiency_t4/`, `robustness/` | Earlier four-model evidence |
| `final_verification_fp16/` | Earlier FP16 evidence |
| `final_verification_original_comparison/` | FP32 comparison against the original CSV |

Recorded evidence is preserved. Official final predictions remain at root as `predictions.csv`. Original logs/manifests can contain historical paths; `docs/REORGANIZATION_MANIFEST.json` maps relocated files.
